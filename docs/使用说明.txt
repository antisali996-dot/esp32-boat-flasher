ESP32 小船 / 遥控器 烧录配对工具（580 转 / 590 转，左右各 20°）
====================================================================

适用：Windows 10 / 11，经典 ESP32 开发板（ESP32-WROOM / ESP32-D0WD，不是 S3 / C3）。
不需要安装 Python、Arduino IDE 或任何编译工具。整个工具就是一个 EXE，
配两套已编译好的固件，全部解压即可用。

本包没有替你烧录任何板子，也没有改动板上现有程序。要升级请自己点“烧录当前板”。


一、第一次使用（只做一次）
--------------------------------
1. 把 ZIP 全部解压到硬盘（例如 D:\ESP32工具）。不要在压缩包里直接双击。
2. 断开动力电池和舵机电源，只留 USB 给开发板供电。
   小船程序上电会自动把电机转到目标转速，不断动力就上电有危险。
3. 双击“双击打开烧录工具.cmd”。
4. 第一次读串口前会弹出一次安全提示，确认已断开动力、只用 USB 后继续。
   同一次运行不会反复问。
5. 工具会列出电脑上的串口，并逐个读取板子身份。

首次运行如果看到“没有检测到串口”，按顺序检查：
- USB 线是不是只能充电的线（换一条确定能传数据的）；
- 设备管理器里有没有串口，没装驱动就装 CH340：https://www.wch.cn/downloads/CH341SER_EXE.html
- 有没有别的程序（串口监视器、其他烧录软件）占着这个串口。


二、先选“固件套装”
--------------------------------
界面最上方是“固件套装”选择框。本包含两套：

- 580 转 / 20°：版本 20261103-20deg-r3，目标 580 转
- 590 转 / 20°：版本 20261103-590rpm-r4，目标 590 转（另有 600 转超速保护）

两套的转向都是中位 90°、逻辑范围 70～110°、脉宽 1278～1722 微秒。

选择框里的转速、角度和版本全部来自发布包里的清单文件，不是从文件名猜的。
选中后右侧会显示这套固件的小船和遥控器的完整固件身份串（FWID）。
每套只使用自己目录下的镜像和烧录组件，两套不会混用。


三、三个主要按钮
--------------------------------
【烧录当前板】
  给列表里选中的那块板写当前所选套装的固件。
  - 默认不备份。想先备份就勾选“烧录前先备份原固件”（8MB 大约 3～5 分钟）。
  - 点之前会弹一次确认框，同时列出：
      【板上现在】角色、目标转速、转向角度、FWID
      【将写入】套装、版本、角色、目标转速、转向角度、FWID
  - 板上固件已经和所选套装完全一致时，会提示“无需重复烧录”，不写入、也不弹确认框。
    确实要重刷，请勾选“即使已匹配也重刷”再点。
  - 跨套装（例如板上是 580、要写 590）会明确列出两套名称；
    如果写入的目标转速低于板上（例如 590 板写 580 固件），会单独弹出降级警告，
    必须由你确认才会继续。不会静默降级。
  - 写入时强制校验；写完还会重启读回身份，两关都过才显示“烧录完成”。
  - 写入失败、校验没报成功、重启读不回来——都算失败，不会显示成功。

【备份原固件】
  单独把整片 Flash 读出来存成文件，只读不写、不擦除。
  文件保存在“记录\日期时间-备份-角色\原固件.bin”，旁边有 SHA256 校验值。
  这个备份里含配对地址，自己留着，别随手发给别人。

【配对两块板】
  两块板同时插在电脑上时用：
  1. 在下面两个下拉框分别选小船和遥控器的串口；
  2. 点“配对两块板”；
  3. 确认框会列出两块板的实际 MAC、当前对端地址，以及兼容性判断；
  4. 确认后只改“需要改”的那一端。

  说明：
  - 只改保存的对端地址，不切换固件套装、不重刷程序。
  - 已经指向正确对端的一端会跳过写入与重启，不会再白写一遍。
  - 如果只有一边成功，会明确告诉你完成到 1/2 还是 0/2、哪一端还没完成。
    排除接线问题后再点一次“配对两块板”，重试只会处理尚未完成的一端。
  - 选同一个串口、或者两次读到同一个芯片 MAC，都会被拒绝。
  - 590 转小船配同一 20° 遥控器是允许的组合：配对只看配对协议版本和转向契约是否一致，
    不要求两端的固件版本号或目标转速完全相同。遥控器不控制油门，转速字段不参与配对判断。
  - 转向契约不同（例如 20° 板配 30° 板）或配对协议版本不同，会拒绝配对并说明原因。
  - 程序过旧、没回应身份查询的板子不能配对，会提示先升级。

  配对用 MAC 过滤，不是加密认证，防不住刻意伪造 MAC 的第三方设备。


四、角色是怎么认的
--------------------------------
- 角色只按芯片 MAC 记。串口号只用来选连接。
- 两块板轮流插，可能都显示 COM8；只要 MAC 不同，工具就不会认错。
- 新板第一次用，必须你在“本板用途”下拉里选“小船”或“遥控器”。
  工具不会按串口号猜角色，也不去搜索、绑定附近的无线 ESP32。
- 选完之后，这次烧录成功才记住这个 MAC 的角色，下次认住。
- 每次烧录、每次重新连接、每次写配对之前，都会再核对一次身份。
  如果你在确认框弹出后换了插另一块板，工具会停下并说明，不会写错板子。


五、固件版本的判断依据
--------------------------------
- 固件会在串口身份行里报 FWID，例如
  JAYFWB3-S20-A70-110-U1278-1500-1722-R580-C580pi2
  这串由真实控制常量拼出来：角色、角度、范围、脉宽、目标转速、控制修订。
- 工具只认“FWID 与本套装清单完全一致”为最新。
- 旧程序即使写着 STEER=20、配对协议也是第 2 版，只要没有 FWID 或 FWID 不同，
  一律按需要烧录处理。配对协议版本（VERSION=2）只说明串口命令兼容，不作为新旧依据。
- 打包时会核对镜像文件里真的存在清单声明的 FWID；清单和镜像不一致，工具会拒绝烧录。


六、写入会动到哪块 Flash
--------------------------------
写入 4 段：bootloader@0x1000、分区表@0x8000、OTA 选择@0xE000、应用@0x10000。
不写 0x9000 起的 NVS 区，所以升级固件不会顺手抹掉已经配好的对端地址。

打包和启动时都会解析清单里的分区表，确认 NVS 区确实不被这四段覆盖、
应用镜像也确实落在 app 分区内。如果某套发布包的分区布局和本工具不兼容，
该套装会显示为“不可用”，并且拒绝对它写入，不会盲目覆盖、也不会声称保留了配对区。


七、当前固件内容
--------------------------------
- 转向：中位 90°，逻辑范围 70～110°（左右各 20°），脉宽 1278～1722 微秒（中位 1500）。
- 调速：580 套装目标 580 转；590 套装目标 590 转并带 600 转超速保护。
  保护逻辑与摇杆死区沿用各自发布包的固件，本工具没有修改任何电机或舵机代码。
- 实际机械角度仍要你自己校准。
- 屏幕上的 540～600 是模拟显示（标 SIM RPM），不代表真实转速；真实转速看 115200 串口。
- 两端的对端地址默认全零，必须用本工具配对；工具不会退回某一对历史 MAC。


八、验证边界（请看这一段）
--------------------------------
已经做到：
- 工具独立编译通过（Windows 自带 .NET Framework 编译器）。
- 模拟测试 138 项全部通过，覆盖：身份解析、FWID 解析、版本判断、分区表校验、
  固件库加载与篡改检测、镜像混用拦截、角色按 MAC 记忆、串口换插、新板选角色、
  默认不备份、写入校验、烧录前复核、两套套装切换、误降级确认、已匹配免重刷、
  配对协议/转向契约兼容判断、已正确一端跳过、部分失败重试、旧固件拦截、安全提示仅一次。
- 用本地真实发布包做了包内自检：两套都可用，分区表解析出 NVS 0x9000，镜像 FWID 与清单一致。
- 图形界面实际启动过（无设备模式），套装选择、版本对比、日志都正常显示。
- esptool 只验证了参数拼装（不存在的串口只报端口不存在），没有连任何设备。

还没做到（未实机验证）：
- 没有在真实 ESP32 上烧录、擦除、读取或写入配对。
- 没有验证真实 USB 串口枚举、CH340 驱动兼容性、DTR/RTS 复位时序。
- 没有验证 NVS 在真实升级后保留配对地址（只验证了写入方案不覆盖 0x9000 起区域）。
- 没有验证真实无线链路、摇杆输入、舵机实际角度、电机带载与保护动作。
- 没有验证两块真实板同时插入时的完整配对流程。
- 没有验证配对配置在真实断电后仍然保持。

所以：模拟测试通过 ≠ 设备验证通过。第一次上板请自己盯着，先断动力、只插一块。


九、目录说明
--------------------------------
双击打开烧录工具.cmd   入口（调用下面的 EXE）
ESP32小船烧录工具.exe  图形工具本体
固件库\580-20-r3\      580 转套装：清单、小船/遥控器镜像、esptool
固件库\590-20-r4\      590 转套装：清单、小船/遥控器镜像、esptool
记录\                  运行时生成的备份与操作日志（可自行清理）
配置\                  角色记忆（按 MAC 记录；删掉只会让新板重新选一次角色）
自检报告.txt           打包时生成的包完整性自检结果
版本说明.txt           两套固件的身份与参数摘要
文件校验.json          本包所有关键文件的 SHA256

“记录”目录可以随时删；里面只有备份和日志，不影响工具运行。
